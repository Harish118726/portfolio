Production-ready, single-page portfolio engineered to showcase hands-on cloud cost governance, billing architecture, and automated financial analytics. 

Designed with a minimal digital aesthetic, full dark-mode palette, and interactive widgets targeted directly at FinOps, Cloud Operations, and Data Analytics hiring teams.

---

## ⚡ Key Features

- **Interactive FinOps Spend & ROI Simulator:** Models baseline monthly cloud burn against dynamic levers (Committed Use Discounts, idle resource cleanup, traffic egress spikes) with instant client-side math and run-rate adjustments.
- **Recruiter CLI Terminal:** Built-in console supporting terminal commands (`help`, `skills`, `finops`, `contact`, `clear`) for quick evaluation.
- **Professional Progression Timeline:** Summarizes core competencies across Google Cloud Billing support, technical operations, and infrastructure analytics.
- **Zero Build Dependencies:** Pure vanilla JavaScript and Tailwind CSS via CDN inside a single `index.html` file—no Node.js build pipeline or bundling required.
